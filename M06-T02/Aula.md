# IA no Workflow: Prototipação e Otimização

## Prototipação com IA: Do Prompt à Página

- O que são protótipos?
- Estrutura de um bom prompt.
- Exemplo prático

**Exemplo RUIM (vago e pobre, resultado genérico)**:

_Crie uma página de uma cafeteria com fotos de café e um botão de contato._

**Exemplo BOM (estruturado e técnico)**

_Aja como um Designer e Desenvolvedor Front-end Sênior. Crie uma landing page moderna para uma cafeteria artesanal (Roastery). **Estrutura**: Seção Hero com título em destaque e botão CTA 'Peça Agora', seção de 'Nossos Grãos' em formato de Grid (3 colunas), e rodapé simples. **Estilo**: Design minimalista, paleta de cores em tons de café (marrom escuro, creme e verde floresta), tipografia Serif para títulos e Sans-serif para corpo, layout responsivo e semântico. **Detalhe**: Use bordas arredondadas nos cards e sombras leves (soft shadows). **Restrição**: Não use JavaScript ou frameworks."_

**Exemplo de "receita" para escrita de prompts**

- ATUAÇÃO: Aja como um [Profissão/Papel].

- OBJETIVO: Crie um [O que deve ser gerado] para [Público ou Contexto].

- REQUISITOS:
  - Estrutura: [Liste as seções, ex: Hero, Galeria, Rodapé].

  - Visual/Estilo: [Cores, Clima, Tipografia].

  - Técnico: [Ex: HTML/CSS puro, Flexbox, Mobile-first, Auto Layout].

- DETALHES: Use [Elementos desejados].

- RESTRIÇÕES: Não use [O que deve ser evitado, ex: Frameworks, Imagens reais, Cores vibrantes].
