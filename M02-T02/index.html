Exemplo 6: O Problema Clássico - 100% + Padding

⚠️ Este é um problema comum: quando você define width: 100% e adiciona padding ou border, o elemento estoura do container pai.

❌ Solução Errada (sem box-sizing)

Width: 100% + Padding: 20px + Border: 3px = OVERFLOW!

Este elemento tem width: 100%, mas estoura porque o padding e border são adicionados FORA da largura.

✅ Solução Correta (com box-sizing)

Width: 100% + Padding: 20px + Border: 3px = ✓ PERFEITO!

Este elemento usa box-sizing: border-box, então padding e border são inclusos na largura total.

📝 Comparação Visual

SEM box-sizing:
Content: 100%
+ Padding: 20px × 2
+ Border: 3px × 2
= 246px de overflow!
COM box-sizing: border-box:
Content: 100%
(padding e border inclusos)
= Encaixa perfeitamente!
