Prompt

Crie uma página web simples (HTML e CSS) para um site de uma cafeteria moderna com foco em demonstrar a abordagem Mobile First e os principais conceitos de responsividade.

A página deve conter:

Um header com o nome da cafeteria
Uma seção principal com título, descrição e botão (ex: “Ver Cardápio”)
Uma imagem principal (ex: café ou ambiente da cafeteria)
Uma seção de produtos com cards (ex: Café, Cappuccino, Latte, Mocha), contendo imagem, nome e preço

Requisitos técnicos

1. Mobile First

2. Layout flexível

3. Imagens responsivas
    - Usar rem para textos
    - Usar clamp() para títulos

4. Tipografia responsiva

5. Media Query
    - Adicionar uma media query utilizando min-width: 768px
    - Altere o layout para:
        - Imagem ao lado do texto
        - Cards em múltiplas colunas
        - Ajuste espaçamentos
        - Melhore o aproveitamento da tela

6. Refinamento visual
    - Design moderno e limpo
    - Espaçamento consistente
    - Botão com hover
    - Cores suave
